# TigerPlayer Utilities Compartment (`utils/`)

This directory contains pure utility functions, math helpers, text parsers, AGSL shader definitions, and platform helpers used across TigerPlayer.

---

## 1. Plain-English Overview

Think of the **Utils Compartment** as the "toolbox and helper belt" of TigerPlayer:
- It contains stateless, reusable functions that perform specific calculations or data formatting tasks.
- Examples include parsing synchronized lyric file formats (`.lrc`), designing equalizer filter coefficients, building AGSL shaders for visuals, or checking Bluetooth audio connection states.
- Classes here are pure and independent, with minimal coupling to Android UI or service lifecycles.

---

## 2. Core Components Breakdown

### Audio & Signal Processing Helpers
* **`BiquadDesigner.kt`**: Calculates biquad filter coefficients ($b_0, b_1, b_2, a_1, a_2$) for Low-Shelf, High-Shelf, Peaking, High-Pass, and Low-Pass parametric equalizer bands.
* **`ReplayGainTagParser.kt`**: Extracts ReplayGain track/album gain values and peak amplitude metadata from ID3v2 and Vorbis comment tags.

### Parsers & File Readers
* **`LrcParser.kt`**: High-performance parser for LRC lyric files, converting timestamped lines (`[01:23.45] text`) into `LyricLine` data structures.
* **`M3uParser.kt`**: Parses M3U and M3U8 audio playlist files, extracting track paths, metadata headers, and durations.
* **`EmbeddedLyricsParser.kt`**: Parses USLT (Unsynchronised Lyric Tag) and SYLT (Synchronised Lyric Tag) frames embedded directly inside MP3/FLAC file headers.
* **`SafPathResolver.kt`**: Translates Android Storage Access Framework URIs into display paths and file handles.

### Graphics & Shader Assets
* **`Shaders.kt`**: Contains AGSL (*Android Graphics Shading Language*) source code strings for GPU canvas shaders (fluid simulation, neon glow, chromatic aberration, vortex warp).

### System & Connectivity Helpers
* **`BluetoothManager.kt`**: Observes Bluetooth A2DP audio device state, codec connection types (LDAC, aptX HD, AAC, SBC), and device battery levels.
* **`NavidromeSecurity.kt`**: Utility for generating Subsonic/Navidrome MD5 token authentication signatures (`md5(password + salt)`).
* **`ArtistUtils.kt`**: Standardizes artist name parsing, feature splitting ("feat.", "ft."), and primary artist extraction.
* **`ContextExtensions.kt`**: Kotlin extension functions on `Context` for toast notifications, system service access, and permission checks.
* **`ElapsedTimeSource.kt`**: High-precision monotonic timer wrapper for performance telemetry and benchmark logging.
* **`AttributionTags.kt`**: Constant definitions for open-source licenses and library attributions.

---

## 3. Design Guidelines & Thread Safety

1. **Stateless & Pure:** Functions in `utils/` must be pure where possible — given the same input parameters, they return the same result without side effects.
2. **Main Safety:** File parsing (`LrcParser`, `M3uParser`, `EmbeddedLyricsParser`) must execute off the main thread when processing large files.
3. **No UI Dependencies:** Utility classes must never hold direct references to Compose `State` or `View` hierarchies.

## 4. Tabulated Jargon Glossary

| Jargon Term | Plain-English Definition | Role in Utils Compartment | Failure Consequence |
| :--- | :--- | :--- | :--- |
| **AGSL (Android Graphics Shading Language)** | Modern shading language for Android GPU shaders. | Powering real-time fluid and visualizer background shaders in `Shaders.kt`. | Visualizers fallback to plain color backgrounds or fail to compile. |
| **LRC File** | Standard text file format for synchronized lyrics with timestamps. | Parsed by `LrcParser.kt` to synchronize lyrics text with song progress. | Lyrics display out of sync or fail to load. |
| **Biquad Filter** | Second-order recursive digital filter. | Coefficients generated by `BiquadDesigner.kt` for parametric equalizer bands. | Audio distortion, pops, or incorrect frequency boost/cut. |
| **MD5 Salt** | A random string added to passwords before hashing. | Computes secure Navidrome auth signatures in `NavidromeSecurity.kt`. | Authentication fails when logging into Navidrome server. |
