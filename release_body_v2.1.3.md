# TigerPlayer v2.1.3

## Release Notes

### Fixed
- **Spotify**: Surface actionable UI element for Spotify App Remote reauthorization in Cloud Archives and Full Player screens. Added a persistent reauth banner with one-tap "Re-authorize Spotify" button and clear status feedback on successful reauthorization. (#201)

### Added
- **F-Droid**: Reproducible builds support with binary verification metadata and allowed signing keys documentation. (#246)

## What's New in v2.1.3

This patch release includes:
- Improved Spotify App Remote reauthorization workflow
- F-Droid reproducible builds support for better transparency and security
- Enhanced documentation for release signing and key management

## Installation

### For F-Droid
The FOSS flavor (`app-foss-release.apk`) is available on F-Droid and can be installed without any proprietary dependencies.

### For Direct Installation
Download the desired APK flavor:
- **app-foss-release.apk** - F-Droid compatible (recommended for F-Droid submission)
- **app-full-release.apk** - Full feature set with Spotify App Remote integration

### For Google Play
Use the `app-fullRelease.aab` (App Bundle) for Play Store submission.

## Features
- 🎵 Local music playback with Media3 / ExoPlayer
- 🎧 Spotify App Remote integration (full flavor only)
- 🧠 On-device music discovery and listening analytics
- 🌊 Real-time fluid visualizer with audio-reactive effects
- ⚡ Jetpack Compose UI with a custom neon design system
- 💾 Room-powered library, history, and analytics storage
- 🔒 Spotify Authorization Code + PKCE authentication

## Build Artifacts

### Downloadable Files
- **app-foss-release.apk** - F-Droid compatible, no proprietary dependencies (unsigned)
- **app-full-release.apk** - Full feature set with Spotify integration (unsigned)
- **app-fullRelease.aab** - Android App Bundle for Play Store (unsigned)

### Verification & Technical Details
- **mapping-full.txt** - R8 ProGuard mapping for full flavor (for debugging)
- **mapping-foss.txt** - R8 ProGuard mapping for FOSS flavor (for debugging)
- **SHA256SUMS.txt** - SHA-256 checksums for all artifacts (for integrity verification)
- **tigerplayer-sbom.spdx.json** - Software Bill of Materials in SPDX format

### Build Information
These artifacts are **unsigned build output** generated by the GitHub Actions "Release candidate" workflow. They are provided for:
- ✅ Verification of reproducible build capability
- ✅ Manual testing and validation
- ✅ F-Droid build verification (F-Droid signs independently)
- ✅ Development and staging deployment

**Note**: These APKs/AAB are unsigned and are build evidence only. For production distribution:
- **F-Droid**: Will independently build and sign the `foss` flavor from source
- **Google Play Store**: Requires signing with your production keystore before upload
- **Direct Installation**: Sign with your keystore before distributing to users
